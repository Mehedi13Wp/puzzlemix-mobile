# PuzzleMix fruit icon

Created with the built-in image generation tool. Master artwork:
`puzzlemix-fruit-master.png`. Play Store icon: `store/puzzlemix-play-icon-512.png`.
Android launcher sizes are checked in under `android-res` and applied by
`python tools/apply_app_icon.py` after Android shell generation.

Prompt: Professional fruit sorting puzzle game icon, deep forest green
background, glossy orange and strawberry inside a glass jar, bold centered
composition, sculpted 3D illustration, clear at small sizes, no text, border
or watermark.
