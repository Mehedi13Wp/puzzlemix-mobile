# PuzzleMix 0.6.11 (18) startup hotfix

Play-installed 0.6.10 (17) fails before the first Flutter frame with
`NoSuchMethodError: SharedPreferencesApiRegistrar.getAll` because R8 rewrites
Kotlin coroutine types used by the shared_preferences_android 2.5.0 JNI API.

Apply the Kotlin runtime keep rules from Pigeon's official native interop
guide. Keep shared_preferences dependencies, preference keys and stored data
unchanged. Persist the rules outside the generated Android directory and
restore them for every generated Play shell.

Build both production bundles and a minified DEV release APK. Verify the
minified DEV release on a physical phone before recommending the new AAB.
The Play signing identity remains unchanged. Do not uninstall production
PuzzleMix or clear user data. Final Play-delivered update verification remains
required after the Alpha release is published.
